# HAGISIRO — 캘린더 · 할 일 · 출결

설정 없이 `index.html`만 열어도 **이 기기에만 저장**되는 모드로 바로 써볼 수 있어요.
(크롬에서 파일을 직접 열면 서비스워커·로그인은 안 되고, 아래 3단계를 거쳐야 어디서든 쓸 수 있어요.)

## 쓰는 법

**캘린더 보기**
- 오른쪽 위 `월별` / `이번 주` 로 전환. `이번 주`는 이번 주를 기준으로 **전체 주 개수(1~6)** 와 **지나간 주 개수(0~5)** 를 ⋯ → `화면 설정`에서 정해요. ←/→ 는 한 주씩 이동.
- `화면 설정`에서 **음력 날짜**, **24절기**, **공휴일**(설날·추석·대체공휴일까지 자동 계산)을 켜고 끌 수 있어요. 공휴일은 날짜가 빨갛게 보여요.
- **구글 공휴일 연동**(로그인 필요)을 켜면 구글 '대한민국의 휴일' 캘린더에서 임시공휴일까지 가져와요.
- **밤 모드**(자동/낮/밤), **위젯 투명도**(바탕화면 위젯 모드에서만), **완료한 할 일은 맨 아래로** 도 여기서 정해요. 이 설정들은 기기마다 따로 저장돼요.
- 상단 `연락처` · `일과 진행 시간표` · `내 시간표` 버튼: 누르면 팝업으로 보여줘요. 내용은 ① 엑셀(.xlsx/.xls/.csv) 올리기 ② 이미지 올리기(자동 압축) ③ 직접 입력/엑셀에서 복사해 붙여넣기(표로 표시, 전화번호는 누르면 전화 걸기) 중 편한 방법으로 넣어요. 엑셀 변환 도구는 처음 올릴 때만 인터넷에서 받아와요.

**할 일**
- 날짜 칸을 **더블클릭** → 바로 입력. **엔터**=다음 줄, 빈 줄에서 엔터(또는 Esc/바깥 클릭)=저장 끝. 앞의 점(불릿)을 누른 채 끌면 여러 줄이 선택돼요.
- 더블클릭하면 아래에 아이콘 막대가 나타나요: **✓ 취소선(완료)**, **팔레트(글자색·배경색)**, **반복**.
- **반복**: 매일(주말 제외 가능) · 매주(요일 선택) · 매달(N일) · 매년(N월 M일, 음력 선택 가능). 같은 팝업에서 반복 일정 관리(수정·삭제)도 해요. 반복 일정을 그날만 지우거나 완료해도 다른 날엔 영향이 없어요.
- 빈 곳에서 끌어 영역을 잡으면 항목이 선택되고 아이콘 막대가 떠요 (Esc로 취소).
- 모바일은 날짜를 한 번 누르면 아래에서 입력창이 올라와요.

**출결** (상단 탭 "출결")
1. 처음에 `학급 만들기` → 번호·이름 붙여넣기 (엑셀에서 복사해도 OK)
2. 입력창에 문장으로 쓰고 엔터 → 그 날짜의 **일별 보기**로 이동해서 결과가 바로 보여요.
3. 일별 보기에서는 학생마다 `종류 ▼ → 교시 범위 → 조회·1~N교시·종례 빗금(/) → 사유` 순서로 직접 고칠 수도 있어요.

종류는 **17가지**: 출석 + {질병, 미인정, 기타, 출석인정} × {결석, 지각, 조퇴, 결과}. 드롭다운에서 `출석`을 고르면 기록이 지워져요.

| 입력 | 빗금이 쳐지는 칸 |
|---|---|
| `홍길동 11월 2일 감기로 조퇴(2교시)` | 2교시 ~ 종례 (질병조퇴) |
| `홍길동 2교시 후 조퇴` | 3교시 ~ 종례 |
| `홍길동 3교시까지 지각` | 조회 ~ 3교시 |
| `홍길동 감기로 2교시 등교` | 조회, 1교시 (질병지각) |
| `홍길동 결석` | 조회 ~ 종례 (종일) |
| `홍길동 3교시 결과` / `1~3교시 결과` | 3교시 / 1~3교시만 |
| `홍길동 생리통으로 조퇴 3교시` | 사유가 생리·월경이면 자동으로 **출석인정** |
| `홍길동 기타결석 집안일` · `김철수 미인정지각 2교시` | 드롭다운 이름 그대로 써도 OK |
| `이영희 11/3~11/5 독감으로 결석` | 3일치 한 번에 (주말 자동 제외) |
| `홍길동, 김철수 금요일 체험학습 결석` | 여러 명 한 번에, 사유구분 "출석인정" |
| `3번 오늘 두통으로 조퇴 4교시` | 번호로도 입력 가능 |

- 사유구분은 사유 단어로 자동 분류 (질병 · 미인정 · 기타 · 출석인정). 틀리면 일별 보기 드롭다운에서 바꾸면 돼요.
- 날짜를 안 쓰면 지금 보고 있는 날짜로 기록. 저장 직후 "되돌리기" 가능. 같은 학생·날짜·결석/지각/조퇴/결과면 덮어써요.
- 한 학생은 하루에 기록 1건만 가능해요. 사유 없이 지각·조퇴 등을 입력하면 **미인정**으로 기록돼요.
- **교시 수 설정**: 출결 화면 오른쪽의 `교시 설정`(또는 ⋯ 메뉴)에서 **요일별 기본 교시 수**를 정해요. 단축수업처럼 특정 날만 다르면 일별 보기 위쪽 `이 날 교시 수`에서 그 날만 바꿔요 (`기본값으로`로 복귀). 교시 수를 바꿔도 "N교시~종례" 같은 범위는 그 날 기준으로 알아서 맞춰져요.
- **주별 보기**: 학생 × 월~금 표로, 그 주에 언제 어떤 사유로 빠졌는지 한눈에 봐요. 칸을 누르면 일별 보기로 이동.
- **월별 보기**: 학생 × 날짜 표와 결석/지각/조퇴/결과 합계. 날짜를 누르면 그 날 일별 보기로 이동.
- `CSV` 버튼으로 그 달 기록을 엑셀용으로 내려받기 (종류·교시 범위·사유 포함).

> 문장 해석은 **규칙 기반**이라 오프라인에서도, 무료로, 즉시 돼요. 예상 못 한 말투가 있으면 알려주세요 — 규칙을 추가하면 돼요.

## 3단계로 인터넷 연결하기 (한 번만)

### 1) Firebase 만들기
1. https://console.firebase.google.com → **프로젝트 추가** (애널리틱스는 꺼도 됨)
2. 프로젝트 홈에서 **`</>` (웹 앱 추가)** → 이름 아무거나 → 나오는 `firebaseConfig` 값을 **`config.js`** 에 붙여넣기
3. 왼쪽 메뉴 **빌드 → Authentication → 시작하기 → Google 사용 설정** (지원 이메일 선택)
4. **빌드 → Firestore Database → 데이터베이스 만들기** → 위치 `asia-northeast3 (서울)` → **프로덕션 모드**
5. Firestore **규칙** 탭 → 기존 내용을 지우고 `firestore.rules` 내용을 붙여넣고 **게시**
   - ⚠️ 학생 출결 정보가 들어가므로 이 단계가 가장 중요해요. 내 구글 계정으로 로그인한 나만 읽고 쓸 수 있게 막아줘요.

### 2) GitHub Pages에 올리기
1. GitHub에서 새 저장소 만들기 (예: `hagisiro`)
2. 이 폴더의 파일 전체를 업로드 (`Add file → Upload files`)
3. 저장소 **Settings → Pages → Branch: main / (root) → Save**
4. 1~2분 뒤 `https://내아이디.github.io/hagisiro/` 로 접속

### 3) 로그인 허용 도메인 추가
- Firebase **Authentication → 설정 → 승인된 도메인 → 도메인 추가** → `내아이디.github.io`

끝! 주소로 들어가서 **Google로 시작**.
처음 로그인할 때 이 기기에 저장돼 있던 데이터가 있으면 계정으로 옮길지 물어봐요.

## 모바일에 앱처럼 설치
- **안드로이드(크롬)**: 주소 접속 → 메뉴 ⋮ → **앱 설치** (또는 홈 화면에 추가)
- **아이폰(사파리)**: 공유 버튼 → **홈 화면에 추가**
- **PC(크롬/엣지)**: 주소창 오른쪽 설치 아이콘 → 별도 창 앱으로 실행 (로그인도 정상 동작)

## (선택) 구글 캘린더 일정 함께 보기
읽기 전용으로 내 구글 캘린더 일정(과 공휴일)을 날짜 칸에 연한 초록색으로 같이 보여줘요.
1. https://console.cloud.google.com 에서 Firebase 프로젝트와 같은 프로젝트 선택 → **API 및 서비스 → 라이브러리 → Google Calendar API → 사용**
2. 앱 오른쪽 위 ⋯ 메뉴 → **구글 캘린더 일정 함께 보기** → 권한 허용
   - "확인되지 않은 앱" 경고가 뜨면 **고급 → 이동**을 눌러 진행 (내가 만든 앱이라 정상이에요)
- 보안상 접속 토큰이 약 1시간짜리라, 시간이 지나면 상단에 "구글 캘린더 다시 연결" 버튼이 나와요.

## 보안 · 개인정보 메모
- `config.js`의 apiKey는 공개돼도 괜찮은 값이에요. 데이터 보호는 `firestore.rules`가 해요.
- GitHub 저장소가 public이어도 **코드만** 공개되고, 학생 데이터는 Firestore(내 계정 전용)에만 있어요.
- 학교 정책상 실명 저장이 걱정되면 명단에 이름 대신 이니셜/번호만 넣어도 똑같이 동작해요.
